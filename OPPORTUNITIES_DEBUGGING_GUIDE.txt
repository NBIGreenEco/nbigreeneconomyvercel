3. Error messages were too generic to identify the real problem

## Firestore Rules - What Changed

### Old Rule (BROKEN):
```
match /opportunities/{opportunityId} {
  allow read: if true;
  allow write: if isAdmin();
  allow delete: if isAdmin();
}
```

### New Rule (FIXED):
```
match /opportunities/{opportunityId} {
  allow read: if true;
  allow create: if isAdmin() && request.resource.data.keys().hasOnly(['name', 'category', 'description', 'link', 'linkText', 'createdAt', 'updatedAt']);
  allow update: if isAdmin() && request.resource.data.keys().hasOnly(['name', 'category', 'description', 'link', 'linkText', 'createdAt', 'updatedAt']);
  allow delete: if isAdmin();
}
```

### Enhanced isAdmin() Function (FIXED):
```
function isAdmin() {
  return request.auth != null && (
    request.auth.token.email == 'nbigreeneconomy@gmail.com' ||
    exists(/databases/$(database)/documents/admins/$(request.auth.token.email))
  );
}
```

This now checks:
1. User is authenticated (request.auth != null)
2. AND either:
   - Their email is the hardcoded admin email, OR
   - Their email exists in the /admins/ collection

## Required Firestore Collection Setup

### Admin Collection Structure
You MUST have this in Firestore:

**Collection:** `admins`
**Document ID:** `nbigreeneconomy@gmail.com` (your admin email)
**Fields:**
```json
{
  "isAdmin": true
}
```

### Example Path: `/admins/nbigreeneconomy@gmail.com`
```
admins/
└── nbigreeneconomy@gmail.com (document)
    └── isAdmin: true (boolean field)
```

## Common Error Messages & Solutions

### ❌ "Permission denied: You do not have permission..."
**Cause:** You're not recognized as an admin
**Solution:**
1. Check if document exists in `/admins/` collection
2. Verify your email matches exactly (case-sensitive)
3. Make sure `isAdmin: true` is set
4. Sign out and sign back in

### ❌ "Authentication error: Please sign in again"
**Cause:** Firebase can't verify your identity
**Solution:**
1. Click sign out (if available)
2. Sign in again with your admin email
3. Clear browser cache (Ctrl+Shift+Delete)
4. Try a different browser

### ❌ "Error saving opportunity. Please try again."
**Cause:** Unknown error
**Solution:**
1. Open console (F12)
2. Look for detailed error message
3. Check if fields are correct (name, category, description required)
4. Try again

### ✅ "Opportunity added successfully" → Works!
